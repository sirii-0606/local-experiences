# 2026-09-26-06 · M5: HTTP API + chat intent parsing

## What changed
- `main` was fast-forwarded to M4 (`6cc897e`) at the team's request.
- **`backend/app/main.py`** is a FastAPI app. It's stateless: the client sends `state` and `itinerary` back on every call.
  - Endpoints: `GET /health`, `GET /catalog`, `POST /discover`, `POST /plan` (returns the plan plus `validate` problems), `POST /events` (returns a `Replan` plus problems), and `POST /chat` (text → state → recommendations + excluded + plan).
  - Unknown experience ids get a `422`.
  - There's no CORS; the frontend should use a Vite proxy (see `docs/api.md`).
- **`backend/app/intent.py`**:
  - **`ParsedRequest`** records only what the traveler said. `None` means "keep the previous value", which is what makes refinements like "actually, less crowded" work.
  - **`parse_rules`** is the offline parser. It handles money (₹/Rs/rupees/budget), clock ranges ("4–6 pm", "until 7pm"), durations ("2 hours", "half an hour", "90 minutes"), groups ("family of 4 with two kids", "my parents", "couple", "solo", child ages), accessibility, crowds, indoor, rain, pace, mode, a keyword → `Tag` map, and place names.
    - Place names are matched against `places.json`, with aliases for "jkk" and "railway station". **The place is matched first and stripped from the text**, so "near City Palace" doesn't count as a heritage intent.
    - The regexes are word-bounded, so "train" doesn't read as rain, "workshop" as shopping, "theatre" as eat, or "Show me" as a performance.
  - **`parse_llm`** calls `claude-opus-5` through `client.beta.messages.parse(output_format=ParsedRequest)` with `effort: low` and server-side refusal fallback (`fallbacks="default"`, beta `server-side-fallback-2026-07-01`). The system prompt lists the known place names.
  - **`parse()`** chooses a parser from `INTENT_PARSER` (`auto`/`llm`/`rules`). If the LLM fails for any reason, it falls back to the rules, and the response's `parser` field reports which one ran.
  - **`to_state()`** merges the parsed request into the previous state. It rebuilds the group only when the group was mentioned, and it defaults the location to Hawa Mahal, the window to now → +3 h, and the budget to ₹2000.
- **`backend/pyproject.toml`** now depends on fastapi, uvicorn and anthropic (1.8, which uses `httpx2`). httpx is a dev dependency, for FastAPI's `TestClient`.
- **Tests** (48 pass, 1 skipped):
  - `tests/test_intent.py`: parser cases and state merging.
  - `tests/test_api.py`: scenario A through `/chat` offline, refinement, scenario B (delay + rain) through `/events`, `/discover`, `/plan`, `422` handling, and LLM failure → rules fallback.
  - An **offline check of the Claude request shape**: an `httpx2.MockTransport` checks the model, the fallbacks header and parameter, effort, the JSON-schema format, and the place list, and parses a canned structured reply.
  - `test_llm_parser_live` only runs with `RUN_LLM_TESTS=1`, because it costs money.
- **`docs/api.md`** is the API contract for the M6 and M7 tracks: endpoints, the UI flow, abridged shapes taken from a real response, and demo reproducibility via `now`.
- **`CLAUDE.md`:** the git rule now says `main` is unprotected and fast-forward is allowed. Added LLM notes and the run command.
- **`README.md`:** added a "Run it" section.

## Known gaps
- Run `RUN_LLM_TESTS=1 ANTHROPIC_API_KEY=... pytest -k live` once to confirm the real Claude call.
- The rule parser is English-only and keyword-based. Hindi is M9.
- The LLM does not rephrase explanations. The engine's reasons are already readable, so this is skipped (YAGNI).
- `SEED` is loaded once at import. M7 provider edits need a writable store; plan to overlay SQLite rows onto `SEED` at request time.
- There's no auth or rate limiting on the API. It's a local demo (M9).
