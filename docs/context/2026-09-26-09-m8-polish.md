# 2026-09-26-09 · M8: feedback loop, group mode, demo readiness

## What changed
- `main` was fast-forwarded to M7 (`1ab9f53`) at the team's request.
- **The feedback loop** (doc §5.2, §9.2 step 8, §12.3 user control):
  - `TravelerState.learned` (tag → −1..1) and `TravelerState.rejected` (ids) are new. Both are carried by the client, so the server stays stateless.
  - `engine/learn.py` has `learn(state, exp, feedback)`: accept is +0.3, "not my thing" is −0.3, no reason (skip, or reject without a reason) is −0.1, and practical reasons (too expensive, too far, wrong time) change nothing. Suitability tags (`family`, `kids`, `vegetarian`, `evening`) are never learned. A reject hides the item for the session.
  - `rank.py` gets a new `learned` factor (weight 0.20) averaged over the experience's taste tags, so a single shared generic tag doesn't count as "similar". Rejected ids appear in "why not" as "you said no to this earlier". New reasons: "similar to things you liked" / "similar to things you passed on", plus group reasons ("especially for Asha" / "something for everyone in your group").
  - `POST /feedback` returns the new state and fresh recommendations. It also logs an aggregate (`experience_id`, kind, reason) to SQLite.
  - Provider insights now include `accepted` and `passed` counts, and traveler pass reasons are merged into "why not chosen".
- **Frontend:**
  - Each card has "Add to plan" (which also records an **accept**, but only if the add succeeds) and a "Not for me…" select (not my thing, too expensive, too far, wrong time, just skip).
  - A **"Learned from you"** chip row: ▲/▼ per tag, tap to forget.
  - **`GroupEditor.tsx`**: per-member name, age, interests (with a tag datalist; unknown words are dropped) and wheelchair need; add or remove people. Updating re-ranks and re-checks the current plan.
  - The provider insights panel shows added/passed counts.
- **`scripts/dev.py`** is a one-command start: it installs on first run, runs the API and web app, `--reset` wipes the demo DB, and Ctrl+C stops both (killing the whole process tree on Windows).
- **`docs/demo.md`** is a 5-minute script with talking points and a fallback plan.
- `README.md` was rewritten for a stranger or judge: pitch, one-command run, how it works (diagram), trust and privacy.
- Also updated: `docs/api.md` (`/feedback`), `decisions.md` (learning rules), `CLAUDE.md` (the `dev.py` command), and roadmap M8 ✅.
- **Tests:** 66 pass, 1 skipped.
  - `tests/test_feedback.py`: reject hides and teaches taste; practical reasons don't change taste; accepts boost similar items and say so, but one generic tag isn't "similar"; no-reason is weaker than "not my thing"; suitability tags aren't taste; group reasons name members; the API round trip and provider pass reasons.
