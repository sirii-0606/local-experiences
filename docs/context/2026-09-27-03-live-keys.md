# Running with the team's API keys

## What changed
- The user's key file was saved as `env` (no dot): not gitignored and never loaded. Renamed to `.env` (gitignored, loaded by `app/env.py`). It was never committed.
- **Tests stay offline whatever `.env` holds:** `conftest.py` forces `INTENT_PARSER=rules` and clears `ADMIN_*` (before this, the suite called the NVIDIA API and failed).
- **LLM output is validated and merged with the rule parse** (`intent.merge`): malformed clock times and implausible numbers become "not said"; the rules win on times, money, minutes and head counts, and fill gaps; the LLM keeps meaning. Prompt: never copy the current time into `start_time`.
- **LLM deadline** `LLM_TIMEOUT_S` (default 10 s; `max_tokens` 800, compact schema). Past it, the rule answer is used.
- `/chat` notes when nothing matches the asked-for intents ("closest alternatives").
- **Weather backup:** with `WEATHER_PROVIDER=auto`, the `WEATHER_API_KEY` (verified: OpenWeatherMap) is tried when Open-Meteo is unreachable.
- `.env.example` documents `LLM_TIMEOUT_S`, the weather backup, the 8-character admin password rule and `LIVE_DATA`.

- **Follow-up from testing ("quick bite" in Pune):** "bite", "hungry", "brunch", "cafe", "coffee", "restaurant" now mean food; open data includes eateries (Wikidata restaurant/café/bakery, members-only clubs skipped; areas fetched before 27 Sep 10:00 refresh once); the chat reply lists the top picks with their reasons, what was ruled out, and says plainly when it knows no places for what was asked or didn't catch a preference; cards have "Why this?" (all reasons, ⚠ included) and a "Why not these?" panel lists every ruled-out place with its reasons; the demo clock starts at the real current time.

## Why
The user added real keys ("now you can even use the API"). Measured, not assumed: the NVIDIA model answers in 0.3–30 s and sometimes returns malformed fields.
